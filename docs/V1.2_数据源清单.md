## 四、数据源注册约定（与 registry/systems 表对齐）

每个真实数据源接入时须在 `platform.systems` 注册，并带：

```text
system_id / name / type（ERP|MES|PLM|CRM|FILE|API）
owner_domain
contact（对接人）
interface_mode（DB_READONLY | REST | FILE | API）
schema_doc_ref（字段清单文档）
```

字段清单文档作为数据源 Owner 确认件存档，与 A2 本系统审核的"主数据匹配/业务规则"直接挂钩。
