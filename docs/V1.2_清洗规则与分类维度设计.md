## 一、清洗规则注册表（首批规则，仅首链路对象）

规则字段见契约（rule_id / rule_name / object_type / field / rule_type / condition / transformation / severity / owner / version / effective_from / effective_to / auto_fix / review_required）。所有自动修复必须留痕 `fixAudit`（before/after/rule 引用/executed_at/confidence）。

| rule_type | 示例规则（首批） | 对象.字段 | severity | auto_fix | review_required |
| --- | --- | --- | --- | --- | --- |
| FORMAT | 日期统一 ISO8601（2026/9/14 → 2026-09-14） | ORDER.order_date 等 | WARN | true | false |
| NORMALIZATION | 客户名称去空格/全半角统一 | CUSTOMER.name | WARN | true | false |
| DEDUPLICATION | 同 source_id + 同 payload 重复记录去重 | 全对象 | BLOCK | true | false |
| MAPPING | 状态码映射（"已确认"→CONFIRMED） | ORDER.status | INFO | true | false |
| RANGE_CHECK | 金额/数量 > 0；单价在合理区间 | ORDER.lines | BLOCK | false | true |
| REFERENTIAL_CHECK | order.customer_code 必须命中 CUSTOMER 主数据 | ORDER | WARN | false | true |
| BUSINESS_RULE | delivery_date ≥ order_date | ORDER | BLOCK | false | true |
| UNIT_CONVERSION | 件/箱换算（按物料 unit） | MATERIAL.unit | INFO | true | false |
| CURRENCY_NORMALIZATION | 币种码大写 + 汇率换算留痕 | ORDER.currency | INFO | true | false |
| ENTITY_RESOLUTION | 客户别名归一到 Canonical Entity（见第三节） | CUSTOMER | WARN | true | true |

## 二、标准化字典（第一批）

| 字典 | 内容 |
| --- | --- |
| 币种 | CNY / USD / EUR（大写码，异常记 WARNING） |
| 单位 | 件（默认）、箱、kg；换算系数进字典表 |
| 日期 | ISO8601 `YYYY-MM-DD` / RFC3339 时间戳 |
| 客户名称 | 工商全称为 Canonical（实体解析产出），别名保留 |
| 产品/物料编码 | 大写、无空格（source_id 规则已由 SOURCE_ID_PATTERN 约束） |
| 状态码 | 订单：CONFIRMED / SHIPPED / CLOSED；产品：ACTIVE / 验证中→VERIFYING |

## 三、实体解析（Entity Resolution，T11）

```text
"宁波恒剑光电" / "宁波恒剑光电科技有限公司" / "恒剑光电" / "HJGD"
        ↓ 匹配（别名表 + 规则）
Canonical Entity：宁波恒剑光电科技有限公司
        ↓
别名全部保留（不得删除历史来源值），Canonical 引用写入 CUSTOMER
```

设计要点：
- 别名表 `governance.entity_aliases`：alias → canonical_ref + source + confidence；
- 匹配策略首批：精确 + 去空白/去后缀（有限公司/有限责任公司）+ 人工确认（AI 建议仅标注置信度）；
- 解析结果写入 lineage（ENTITY_RESOLUTION 环节），人工确认后生效。

## 四、分类维度模型（Dimension + Taxonomy + Tag，T12）

### 4.1 首批维度（仅四个）

| 维度 | 用途 |
| --- | --- |
| CUSTOMER | 客户等级 / 生命周期 |
| PRODUCT | 产品线 / 状态 |
| MATERIAL | 物料类别 |
| ORDER | 金额档 / 风险档 |

### 4.2 最小 Taxonomy 树

```text
CUSTOMER
├─ 等级：战略客户 / 重点客户 / 普通客户
└─ 生命周期：新客户 / 老客户

PRODUCT
├─ 整机 / 配件
└─ 状态：ACTIVE / VERIFYING

MATERIAL
├─ 关键料（X-100 类）/ 普通料
└─ 通用件 / 专用件

ORDER
├─ 金额档：小额（<10万）/ 中额（10~50万）/ 大额（≥50万）
└─ 风险档：高风险 / 中风险 / 低风险
```

### 4.3 首批 Tag 集合

```text
high-risk / new-customer / new-product / late-delivery / high-margin /
low-margin / slow-moving / quality-alert / cash-risk / strategic
```

### 4.4 分类治理（V1.1 第三十七节）

- 来源三类：RULE_BASED / HUMAN_MAINTAINED / AI_ASSISTED；
- 正式主数据分类必须有业务 Owner；AI 只能建议（confidence + 规则校验/人工审核后生效）；
- AI 禁止直接修改：战略客户等级、合格供应商等级、财务科目、产品正式分类、品质正式等级、重大风险正式状态；
- 分类版本化字段见 classification.schema.json。
