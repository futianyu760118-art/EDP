**实现**（本模块为领域表唯一读写口；tools 与 ingest 均只 import 本 service）：

```python
"""projections 服务：SourceRecord → 领域快照表投影（同事务）+ 领域查询口。

- project_record：按 object_type 分派投影器；投影异常由调用方（管道）捕获
  记 warning，不阻断三元组落库；
- resolve：自然键 → object_id（RLS 会话内查询，跨租户=不存在）；
- 查询函数（get_order/list_orders/get_inventory/list_purchase_orders/get_bom/
  get_lead_times/get_customer）供 tools 模块使用，返回值领域 ORM 实例。
"""

RESOLVABLE_TYPES = {"CUSTOMER", "MATERIAL", "PRODUCT", "SUPPLIER"}


async def resolve_object_id(sess, tenant_id: UUID, object_type: str, source_id: str) -> UUID | None:
    return (await sess.execute(
        select(BusinessObject.object_id).where(
            BusinessObject.tenant_id == tenant_id,
            BusinessObject.object_type == object_type,
            BusinessObject.source_id == source_id,
        )
    )).scalar_one_or_none()


async def project_record(sess, tenant_id: UUID, record: SourceRecord, object_id: UUID) -> None:
    """按 object_type 分派；未知类型静默跳过（通用对象无投影）。"""
    projector = _PROJECTORS.get(record.object_type)
    if projector is not None:
        await projector(sess, tenant_id, record, object_id)
```

- 各投影器统一模式（以 ORDER 为模板，其余按 spec §2.2 映射表）：
  ```python
  async def _project_order(sess, tenant_id, record, object_id):
      payload = record.payload
      customer_id = await resolve_object_id(sess, tenant_id, "CUSTOMER", payload.get("customer_code", ""))
      values = dict(
          order_id=object_id, tenant_id=tenant_id, order_no=record.source_id,
          customer_id=customer_id, amount=payload.get("amount"),
          currency=payload.get("currency", "CNY"), status=payload.get("status", "未知"),
          order_date=_parse_dt(payload.get("order_date")),
          delivery_date=_parse_dt(payload.get("delivery_date")),
          snapshot_at=record.occurred_at, attributes=_rest(payload, KNOWN_ORDER_KEYS),
      )
      await _upsert(sess, SalesOrder, values, pk="order_id", object_id=object_id)
      await sess.execute(delete(SalesOrderLine).where(SalesOrderLine.order_id == object_id))
      for idx, line in enumerate(payload.get("lines", [])):
          sess.add(SalesOrderLine(
              line_id=uuid5(object_id, f"line:{idx}"), tenant_id=tenant_id, order_id=object_id,
              product_id=await resolve_object_id(sess, tenant_id, "PRODUCT", line.get("product_code", "")),
              material_id=await resolve_object_id(sess, tenant_id, "MATERIAL", line.get("material_code", "")),
              quantity=line.get("quantity"), unit_price=line.get("unit_price"),
              amount=_line_amount(line),
          ))
      await sess.flush()
  ```
- `_upsert(sess, Model, values, pk, object_id)`：ORM `sess.get(Model, object_id)` → 存在则逐列赋值（仅覆盖非 None 值，防降级），否则 `sess.add(Model(**values))`；`updated_at`/`updated_by` 由 server_default / 调用方补；
- 行明细统一 `delete → insert`（order_lines/bom_items/milestones）；
- `SUPPLIER_LEAD_TIME`：`_upsert` 改为按 `(tenant_id, supplier_id, material_id)` 查现有行 → 有则更新 `lead_time_days/updated_at`，无则 insert（id=`uuid5(object_id, "lead")`）；
- `_rest(payload, known)`：剔除已映射键与 `owner_domain` 后剩余字段 → `attributes`；
- `_parse_dt`：ISO 字符串/date → aware datetime；缺失 → None（`sales.orders.order_date` 可空）。

**测试**：
- 单测（mapping）：`_rest/_line_amount/_parse_dt` 边界（None/缺键/ISO 串）；
- 集成（test_projections）：直接调 `project_record` 造 9 类记录（依赖顺序）→ 断言各领域表行数/外键解析/行明细替换（同 object_id 二次投影 lines 数不翻倍）；resolve 未命中 → FK 为 NULL 不抛。
