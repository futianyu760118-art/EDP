# EDP 第二周任务（W2）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 交付 W2 两波：① 前端运营总览页 + 业务对象页 + 拦截器收尾（MSW 驱动，M2 周五演示保底）；② 后端数据链路（EDP-010 管道 + EDP-008 证据 + EDP-009 审计 + EDP-024 租户生命周期）+ M2 对账收口。

**Architecture:** 前端 feature-sliced（features/overview、features/registry），数据全走已有 MSW 27 handler，`VITE_USE_MSW` 切真实。后端沿用六文件模块模式；审计走 SQLAlchemy `before_flush` 切面；适配器为纯端口包（edp_adapters），管道落库在 `edp_api/modules/ingest`（import-linter 方向：api 依赖 adapters，反向禁止）。**对 spec 的两处已批偏差**：pipeline 从 `packages/adapters` 移至 `edp_api/modules/ingest`（避免包循环依赖）；`platform.systems` 已有 `adapter_mode`/`auth_config` 列，0008 只补 `last_watermark TIMESTAMPTZ`（原 spec 写 `config JSONB`）。

**Tech Stack:** FastAPI + SQLAlchemy 2 async + Alembic（PG16 分区/RLS）；React 19 + TanStack Query v5 + Tailwind v4 + MSW 2.15；vitest / pytest + testcontainers。

**Spec:** `docs/superpowers/specs/2026-09-16-edp-w2-design.md`（已批准）

export type ErrorPresentation =

  NETWORK_ERROR: { message: "网络异常，请检查连接后重试", presentation: "toast" },

import { message } from "antd";
import { QueryClientProvider } from "@tanstack/react-query";

import { errorSpec } from "@edp/shared";
import { setTenantSuspendedNotifier } from "../features/auth/api";

// 全局兜底 toast：未被页面捕获的查询错误（页面级 try/catch 优先生效）
queryClient.getQueryCache().subscribe((event) => {
  if (event.type !== "updated") return;
  const err = event.action.data as { message?: string; code?: string } | undefined;
  if (!(err instanceof Error)) return;
  const spec = errorSpec((err as unknown as { code?: string }).code);
  if (spec.presentation === "banner" || spec.presentation === "login") return;
  void message.warning(spec.message);
});

      <ThemeProvider>
        <RouterProvider router={router} />
      </ThemeProvider>
    </QueryClientProvider>
  );
