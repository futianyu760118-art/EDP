**实现**（B.5 逐字段；ORM 对齐 A.6 全列——表已存在，无迁移）：

- `service.py` 状态机单点：
  ```python
  TRANSITIONS: dict[str, dict[str, bool]] = {  # from -> {to: human_only}
      "PROPOSED": {"ASSIGNED": False, "REJECTED": False, "CANCELLED": False},
      "ASSIGNED": {"ACCEPTED": False, "CANCELLED": False},
      "ACCEPTED": {"APPROVED": False, "CANCELLED": False},
      "APPROVED": {"EXECUTING": True, "CANCELLED": False},
      "EXECUTING": {"COMPLETED": False, "CANCELLED": False},
      "COMPLETED": {"VERIFIED": True, "CANCELLED": False},
      "VERIFIED": {}, "CANCELLED": {}, "REJECTED": {},
  }
  def allowed_to(status) -> list[dict]  # [{to_status, human_only}]，字典序稳定
  ```
- `POST /actions`（`make_require_access("action", "write")`：JWT `action:execute` / Key `write:action`）：请求 `{case_id, title, action_type, owner?, owner_role?, due_date?, description?}`；case_id 提供且不存在 → 400 VALIDATION_ERROR；201 `{action_id, status:"PROPOSED", created_at}`；
- `GET /actions?status=&owner=&case_id=&limit=`（`action:read` / readonly）：游标（created_at DESC, action_id DESC）简投影含 `allowed_to`；
- `GET /actions/{action_id}`：完整对象 + `allowed_to`；跨租户 404；
- `PATCH /actions/{action_id}/status`（`action:execute`）：`{from_status, to_status, comment?}`——
  1. `to_status` 不在 `TRANSITIONS.get(from_status)` → 422 `INVALID_TRANSITION`（`EdpError.invalid_transition`，extra 含 `allowed_to`；errors.py 已有 422 映射，无需改）；
  2. Human-Only 转移（`TRANSITIONS[from][to] is True`）且 principal 非 HUMAN → **独立会话**审计 `GUARD_DENIED`（复用 decisions/memories 的 record_guard_denied 同构 helper）+ 403 `GUARD_POLICY_DENIED`；
  3. `UPDATE ... WHERE action_id=:id AND status=:from_status`，rowcount=0 → 409 `CONFLICT`；
  4. `comment` 非空 → 同事务创建证据：`evidence.service.create_record`（source_system=`edp`、source_record_id=`{action_id}#{to_status}`、ref_type=`ACTION`、ref_id=action_id、payload=comment）——设计 7.5「审批意见落证据链」；
  5. 回填：to=COMPLETED → `completion_time=now()`；to=VERIFIED → `verified_at=now(), verified_by=principal 显示名`；
  6. 200 `{action_id, status, updated_at}`；
- 审计：切面自动 `ACTION_CREATE`/`ACTION_UPDATE`。

**测试**：单测——转移表全组合（9 态 × 9 目标 × 期望，含终态无出边、两条 human_only=True）；集成——创建（JWT + Key 双轨）→ 列表三过滤 → 详情 allowed_to → 六步走通 PROPOSED→…→VERIFIED → 非法转移 422 且 extra.allowed_to 正确 → from 不符 409 → AI/SERVICE 做 Human-Only 转移 403 + 审计行 GUARD_DENIED → comment 落证据（`GET /evidence?ref_type=ACTION&ref_id=` 可查）→ 跨租户 404。
