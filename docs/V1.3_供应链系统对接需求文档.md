**日期：** 2026-10-15　**对端：** 供应链中台 PostgreSQL（192.168.0.127:15432）

**说明：** EDP 通过逻辑复制（CDC）只读接入订单/库存/工单等表，全程不写贵库、不轮询 SQL。

---

## 一、请贵方配置（DBA 执行，共 3 项）

**1. 开启逻辑复制（需重启数据库，请评估窗口）**

```sql
-- postgresql.conf 修改后重启
wal_level = logical
```

**2. 建专用账号并授权（不要给 root）**

```sql
CREATE ROLE scm_cdc LOGIN PASSWORD '<贵方设定，安全渠道交付>' REPLICATION;
GRANT CONNECT ON DATABASE <库名> TO scm_cdc;
GRANT USAGE ON SCHEMA public TO scm_cdc;
GRANT SELECT ON public.orders, public.inventory /*, 白名单表 */ TO scm_cdc;
```

**3. 建发布（白名单表与下表一致）**

```sql
CREATE PUBLICATION scm_pub FOR TABLE public.orders, public.inventory /*, 白名单表 */;
```

## 三、两点须知

- **对源库影响**：EDP 停止消费超过 24 小时，源库 WAL 会积压占磁盘；约定此时贵方可直接删除复制槽 `edp_debezium_scm` 自保（不影响贵系统业务）。
- **接入前提**：无主键的表不接入（请先补主键或排除）；字段含义不明的表不接入。
